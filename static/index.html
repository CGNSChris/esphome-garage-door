Garage Door Controller

Self-hosted ESPHome firmware for an ESP32-S3 dual-endstop garage door controller. Source: CGNSChris/esphome-garage-door.

First flash (USB)

Connect the board by USB and click install. Use the board's UART USB port if it has both, and Chrome or Edge.

Updates

After the first flash, the device updates itself over WiFi from manifest.json (checked every 6 h, installed only when you press Install in Home Assistant).
